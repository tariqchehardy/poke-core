   High-stakes steps always require explicit user approval.

5. 05_influence-mapper (influence_mapper)
   Maps connections between people, companies, technologies. Surfaces the
   single highest-leverage node for influence.

6. Orchestrator (select_and_run)
   Automatically selects the optimal tool for any objective under strict
